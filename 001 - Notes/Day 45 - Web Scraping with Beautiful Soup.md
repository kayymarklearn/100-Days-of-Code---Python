# **Web Scraping**
> Web scraping is the automated process of using bots to extract large amounts of data from websites, converting unstructured HTML content into structured data like spreadsheets or databases.
> In python we use the Beautiful Soup (bs4) library for web scraping.

### Legalities of Web Scraping
> So,  what is the law on news scraping?
> - Web scraping is generally legal so far as the data getting scraped is not being commercialized (especially when the data is copyrighted.)
> - You cannot scrape data behind authentication.
