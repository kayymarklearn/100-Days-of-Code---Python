# **HTTP Requests**
## Get Requests
> Used to get pieces of data from server or  external system or API
> `requests.get()`
## Post Requests
> Used to send data to an external system
> `requests.post()`

## PUT Requests
> Update or change data in an external system
> `requests.put()`

## Delete Requests
> Delete a piece of data in the external service
> `requests.delete()`
