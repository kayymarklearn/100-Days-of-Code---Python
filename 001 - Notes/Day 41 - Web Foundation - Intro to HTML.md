# **How the Internet works**
#### What is the internet?
> It's basically a long piece of wire (a bunch of cables really) connecting multiple computers together (basically a large network).
> On this network, there are special computers that provide data and files or resources to other devices on the internet, these are called servers.
> Any other device used to access the files and  data are called clients.

# **How do websites work**
> In order to access a website you need a browser (eg. chrome, librefox, brave).
> When you load a website in your browser, three primary files are loaded, html, css and js.
>HTML - Hypertext Markup Language - is primarily used to build the structure of the website.
>CSS - Cascading Style Sheets - is used to style the website (basically the painter or artist).
>JS - Javascript - is the code that allows the website do things or have behaviours.

#### *What is HTML - HyperText Markup Language*
> Defines the content and structure of a website.
> Hypertext means pieces of text that can link to other documents on the website.
> 
> Markup Language is a system for annotating a document with tags or codes to define its structure, layout, and appearance, allowing computers to properly interpret and display content.
> Markup in HTML is done through html tags

##### The Heading Element
> `<h1>Hello World</h1>` 
> ![[html heading tag.png]]
> `<TAG> vs. Element` Anything in <> is a tag, the opening tags, closing tags and content all make up the element.
> The heading element has six levels `h1 to h6`, in decreasing order of magnitude, `h1` being the largest.

##### The paragraph element
> Also used to display text `<p>This is a paragraph</p>`
>  ![[Html paragraph tag.png]]

##### Void Elements
> These are basically elements that do not have content, examples are `<hr />` `<br />`
> Some examples are;
> - `<hr />` [horizontal rule] - used to draw a horizontal line on the page
> - `<br />` [break element] - Used to separate things onto different lines (example poems).
