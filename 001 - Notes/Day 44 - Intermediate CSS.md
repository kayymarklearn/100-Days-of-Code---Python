### **CSS Colors**
>The main color properties are;
>Background-color: changes the the background color of the element.
>Color: changes the text color of an element 
>- name colors;
> `h1 {color: rebeccapurple;}`
> - hex codes:
> `h1 {color: #ff0000;}`

### **CSS Fonts**
> font-weight: used to make the font heavier, the basic keywords are normal or bold. We can also use a number from 100 to 900 to determine the degree of boldness. We can also used lighter or bolder to get a font weight relative to the parent. When you use lighter, it automatically reduces the boldness by 100 and when we use bolder, it increases the boldness by 100.
> 
> font-size: Used to change the size of text (in pixels, px) [1 px=1/96th inch] or in points (pt)[1/72 of inch] or 1em (full width of the letter m)[100% of parent] or rem(relative to the size of root not the parent [html]). rem is a more consistent way of setting font size than em.
> 
> font-family: This determines what the text should look like (typeface wise). Very often this property is given more than one value as contingencies.

### **Text alignment**
> use the text-align property to change the alignment of text, just like in word processors like ms-word.

#### **The Box Model**
> Effectively each element is a box in the html document.
> refer to [Box Model](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Box_model) for more info on the box model
